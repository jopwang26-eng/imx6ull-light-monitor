# 验证结果与边界

截至2026-11-07，项目任务01～09在记录范围内完成阶段验收。日志由开发板实际运行、用户提供输出和原生进程测试共同构成，分别标注，不把工具准备视为硬件验证。

| 项目 | 已观察结果 | 证据 |
|---|---|---|
| KEY0 | 消抖、阻塞/非阻塞、poll、EFAULT保留、事件合并及卸载重载 | [事件接口](validation/2026-11-04-key-event-api.md) |
| 采集/日志 | 100ms周期约61秒，610次成功且全部保存；CSV611行含表头 | [最终准备](validation/2026-11-07-final-preparation.md) |
| 串口/报警 | 五条命令、KEY0切换、双阈值滞回、暂停/故障/退出关闭 | [统一控制](validation/2026-11-07-control-board.md) |
| NFS端口中断 | 中断12秒时采样和查询继续，日志积压；恢复后197条全部报告保存、应用退出0、测试规则清理 | [NFS观察](validation/2026-11-07-nfs-board.md) |
| I²C地址NACK | 真实0x1f只读事务返回-EIO；字符read=-1/errno5，缓冲区未覆盖；应用故障NA/OFF、恢复有效/ON，正式模块恢复正常 | [NACK板测](validation/2026-11-07-i2c-nack-board.md) |
| 原生回归 | 6采集+5日志+7控制，共18项；另有观察器回归 | [控制构建](validation/2026-11-05-control-build.md) |

历史记录按当时状态追加，早期“尚待”不覆盖后续完成证据；以本汇总和最终专项记录为当前结论。

NACK测试不是AP3216C物理断线/断电测试，设备解绑也不是物理I²C故障。没有证明长期可靠性、掉电零丢失、硬实时或物理输出卡死检测。12秒中断未填满64条队列；故障前的STOP/START不算故障期间控制验证。GPIO回读确认与实际声音反馈是不同证据。
